# 先用样例看懂它

两份数据均为本项目手工构造的演示数据，不来自真实用户、学校或企业。无需提供自己的资料就能体验；页面中所有估分、周期与资源都是演示假设，不能复制到真实项目。

## 直接查看

**统一入口：[第一步：选择版本＋设置权重](start.html)**。初始不选中任何版本，切换后展示对应指标，确认前不会读取数据。

下载并解压完整技能包后，用浏览器打开：

| 版本 | 设置偏好 | 比较候选 |
|---|---|---|
| 学术 | [学术偏好页](academic-preferences.html) | [学术比较页](academic-comparison.html) |
| 企业 | [企业偏好页](business-preferences.html) | [企业比较页](business-comparison.html) |

GitHub 的文件页通常展示 HTML 源码；这些是随包离线文件，不是已托管网站。宿主支持 HTML 预览时可以直接展示，否则在对话确认。偏好页与比较页用于分别预览，预览调权不自动联动另一页，也不代表给任何真实任务提交选择。

页面可由已有 Python 3.10+ 执行 `python scripts/build_demo.py --output-dir <可写目录>` 重新生成；只需标准库，不安装依赖，不读取用户数据，不自动打开浏览器。维护时生成到 examples 目录，可同步包内预览文件。

## 数据说明与可核验事实

### 学术样例

每行是一位虚构学生一周的记录；`student_id` 是重复实体标识，`week` 是周序号；`practice_minutes` 为该周练习分钟数，空白为未记录；`quiz_score` 是周末测验得分，范围 0–100。所有练习统计在同周测验前完成；没有更细的事件时间戳。

共 12 行、4 位学生、每人 3 周；S03 第 2 周练习时长缺失。12 行不等于 12 个独立学生。没有随机分组、课程难度、教师、学习动机或其他学校数据。

可以演示同一学生的变化分析、按学生分组验证的设计、缺失值敏感性检查。不能据此证明练习导致分数提升、声称跨校泛化或确认论文创新。未查阅文献，创新度应留空。

### 企业样例

每行是一个已完成交付且退货观察窗已结束的虚构订单；`channel` 为下单渠道，`category` 为商品类别；`promised_days` 为下单时承诺交付天数；`delivery_days` 为订单完成后记录的实际天数；`return_flag` 为完成交付后 30 天内是否退货，1=退货、0=未退货。退货观察窗已结束是本合成场景设定，不是对现实数据的认证。

共 12 行、12 个唯一订单，5 单交付晚于承诺，4 单发生退货。实际交付天数和退货结果在下单时不可用，不能拿来当下单时预测特征。没有成本、毛利、退货原因、客户标识、售后触达记录或分配试验。

可以演示履约复盘、退货原因补录和承诺规则检查。不能判断迟交导致退货、计算真实净收益、做客户级复购分析或将事后字段用于提前预警。

## 第一份交付应长什么样

> 已读取企业样例全部 12 行及本说明：订单标识唯一，字段结构一致。发现 5 单迟交，4 单退货；关联不代表因果。由于成本、原因和行动渠道未提供，先比较履约复盘、退货原因补录、承诺规则检查三个机会假设；潜在净价值留空，选定后补验证条件。
