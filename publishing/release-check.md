## 可复现命令

在技能目录，用已验收的common解释器执行：

```text
python -B -X utf8 -m unittest discover -s tests -v
python scripts/setup_environment.py --profile common --state-dir <已有环境目录>
python scripts/build_demo.py --output-dir <临时演示目录>
```

具备Node 22+和本地Edge/Chrome时：

```text
node tests/startup-browser.mjs <浏览器可执行文件>
node tests/capture-preview.mjs <浏览器可执行文件>
```

第二条命令更新assets中的实际界面截图；不会向模型提交设置。截图生成后检查发布预览，避免引用过期界面。
