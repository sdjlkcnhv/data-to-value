# 企业数据机会发现与价值落地

用于企业拥有多份数据、希望发掘尚未充分利用的价值，却未必知道应当开发什么的场景。与学术分支同等完整。默认工作是**从数据发现业务机会，形成可实施的想法，并逐步把它变成增收、降本、减少损失或改善决策的实际价值**；不要求使用者先带着业务方案、明确瓶颈或收益假设。

主线为：**现有数据 → 已用与未用的信息 → 业务机会 → 具体想法 → 低成本试点 → 实际价值 → 实施与扩展。** 收益评估用于后续筛选和检验，不能替代前面的机会发现。用户已有想法时可以从相应阶段进入，不强制重新选题；只要求发现机会时，交付到候选、关键未知与验证建议，不自动进入试点或完整工程拆分。

## 1．盘点数据及其当前用途

在使用者选择企业版后，先了解行业、主要产品或服务、已有数据用途与可实施范围，再依共享核验规则实际读取数据。业务背景不完整时先做可行的数据诊断，标明未知，提出少量会改变判断的问题；不要求使用者自己先想出项目。

将数据盘点扩展为用途与机会表：

| 内容 | 记录要求 |
|---|---|
| 数据证据 | 文件/表/快照、实际字段、实体、时间范围、质量和来源；定位到核验结果 |
| 已有用途 | 当前报表、系统、规则或分析及其依据；不了解时写待确认，不能将“未见文档”当作从未使用 |
| 可观察信息 | 能描述什么行为、需求、资源、时序或结果；哪些仅为代理测量 |
| 可关联信息 | 哪些表可通过已核验键、粒度和时点连接；报告一对多、覆盖与无法匹配部分 |
| 潜在新用途 | 单份或合法关联后的数据可能新增什么认识、动作或服务；标为机会假设 |
| 当前限制 | 缺什么标签、语义、行动渠道或效果记录；对本机会有何影响 |

将分析单位与业务单位对齐：订单、订单行、客户、工单、设备、班次和快照不能混算。核查连接倍增、重复客户、退款、币种、会计/业务日期和可用时点中与本任务相关的部分。数据之间存在可解释关系才讨论关联，不能为了利用更多数据强行拼表。

## 2．从数据提出新机会与具体想法

候选生成遵循 [方案生成细则](idea-generation.md)，本节补充该版本的价值判断。

先说明已核验数据提供了什么观察或关联能力，再寻找差异、时序关系、重复工作、资源错配、未连接的信息以及尚未服务的需求；尚未实际观察到的现象标为待检验假设。将这些线索连接到具体动作或服务，并提出关键失败条件。发现机会可以改进已有流程，也可以形成新的服务或收入来源；不局限于训练预测器、画报表或证明既有方案有效。

以下仅用于启发检查，必须先有相应字段和事实，不能照搬为已发现结论：

| 有数据支持时的线索 | 可以提出的机会假设 | 仍需成立的条件 |
|---|---|---|
| 订单、库存与到货记录显示不同地点的供需错配 | 调拨、补货或服务组合可能减少失销或积压 | 实体与时间可对齐，实际可调配，收益能覆盖动作成本 |
| 客户使用记录与服务记录形成过去未关联的信息 | 新的服务包或触达时机可能更符合需求 | 使用场景有依据，具备服务能力与适用的数据使用范围，不能把相关性当干预增量 |
| 工单或设备记录显示可重复的等待与故障模式 | 分派、巡检或维护安排可能减少等待和损失 | 可提前获得信息，有人或系统能改变动作，误报与维护成本可控 |
| 多套记录重复核算同一事实或口径冲突 | 数据产品、自动核对或统一指标可能减少返工 | 正确口径可确定，实际使用者会采用，实施与维护负担可接受 |

每个候选用一条可追溯链表达：

```text
已核验数据事实 → 尚未利用的信息或能力 → 可新增/改变的动作或服务
→ 潜在价值及其成立条件 → 最便宜的验证或反证
```

按成熟度记录具体使用者、决策时点、输入字段、输出、现状做法、可触达对象及关键缺口。使用者或动作条件尚不清楚时，可保留有事实线索和可解释价值来源的机会假设，说明如何核实，不能写成可直接上线的方案。想法数量由证据决定，不为凑数列行业通用建议；仅更换模型而不改变动作、服务对象或所回答问题的方案，通常归为同一候选的实现变体。

已有业务目标继续作为约束；没有具体目标时，可在企业背景与数据范围内发现候选。授权范围内可淘汰候选、补证据并继续搜索，记录原因。需要改变已确认目标、已选主线或交付类型，或显著扩大投入与授权范围时，先讨论再推进；不把“留存增长”自行改成“训练流失预测器”。

## 3．筛选值得实施的机会

比较潜在价值、数据准备程度、动作可行性、成本、得到有效证据的速度和关键依赖，并沿用共享的机会假设、可验证方案、已获支持方案三种成熟度。机会假设优先判断是否值得补证据；可验证方案再检查输入、动作及评价条件。对已证实无法形成价值、动作或有效评价且在本任务约束内无修正路径的候选，淘汰或暂缓；条件未知时说明补证据路径，不直接判为无效。

按本轮深度比较与候选有关的现状及合理替代，包括不做改变、修复数据、规则/SQL、仪表盘、现成工具或模型；不要求早期候选遍历所有实现形式。若规则已能解决，不为“智能化”增加模型。论文新颖性可以作为附加价值，不是立项硬门槛。

优先方案说明：为什么这份数据能支持这个想法、比当前用途多产生什么价值、怎样以最低合理成本实现、什么结果会否定它。业务效果未知可以进入有价值的探索；不能因尚无ROI证明而取消机会发现，也不能把未经检验的潜力写成确定收益。

多机会比较时，按主文件链接的评分细则，综合潜在净价值、见效时间、执行成本、落地条件与效果可测量性，默认精选三个方案作可视化比较。时间和成本同时保留原始估算、区间及依据，并按越快/越省得分越高转换；区分取得可用验证结果的时间、上线时间与兑现收益时间，明确成本范围。展示建议后由用户选定方案，不以最高分自动决定试点或开发。

## 4．建立指标与价值合同

主业务指标写清单位、分母、窗口、责任人、数据源和计算规则；例如每100个已关闭工单的返工数，而非没有口径的“效率”。同时给模型/规则指标、业务结果、约束及保护指标。

| 层级 | 示例 | 不能替代什么 |
|---|---|---|
| 数据/流程 | 重复率、对账差异、处理延迟、人工分钟/批 | 不自动等于新增利润 |
| 模型/规则 | 误差、召回、已复核样本精度、拒判率 | 不直接等于干预有效 |
| 决策 | 实际处理数量、正确行动率、每班告警量 | 不自动等于总体客户/设备收益 |
| 业务 | 净损失、缺货天数、服务水平、净留存或可兑现成本 | 需排除重复计算、结构变化和测量偏差 |

价值估算区分基线、可触达规模、采用率、单次增量效果、运营成本与固定投入。可写：

```text
预计净价值 = 可执行动作数 × 单次增量价值 − 动作成本 − 运维成本 − 分摊实施成本
```

每个量注明实测、外部依据、业务假设或未知，给合理区间/盈亏平衡点；没有增量效果证据就只给条件性测算。“模型找出高风险客户”不证明联系这些客户会减少流失；工时下降不必然能全额兑现为现金节省。

## 5．从离线验证到业务试点

按成本逐级推进，用户要求只到某一级时不要自动扩大：

1. **离线重算/历史回放**：验证字段、连接、指标、时间可用性和现行规则；与现状比较，保留不知道/不行动的分母。
2. **影子运行**：在不改变业务动作的情况下记录建议、延迟、稳定性和人工容量。可支持运行可行性，不能直接证明策略收益。
3. **小范围试点**：已有授权下执行；明确动作、责任人、范围、成功/退出门槛。可随机化时按业务单元设计A/B及污染控制；否则说明匹配、准实验或观察比较的假设，不能只用前后差异宣称因果。
4. **扩大与维护**：只有证据和授权支持时扩大，记录版本、监测、失败回退和人工接管。监测效果、成本和输入变化；回退至已知规则，不无限自动更新。

资源估算包含人工标注/复核、接入、算力、维护和动作本身成本。罕见故障的高准确率可能来自永远预测正常；减少告警可能只是漏报更多。容量固定时同时比较每班工作量、错误行动成本和漏失成本。

## 6．工程交接

在共享issue格式基础上补齐：使用者/维护责任、刷新频率、输入与输出契约、失败处理、试点范围、监测与回退条件。实时任务说明可用时间与延迟，不以历史平滑数据的离线分数认证真实线上表现。

成果可以是可靠数据表、查询、质量检查、指标字典、规则或模型、操作报告、试点评估；按真实动作选择。接口所需身份/字段与模型输出要可解释地对应业务实体，不能依靠行序或猜测关联。

验收分两层：工程验收看结果能正确产生且可追溯；价值验收看业务指标是否达到约定且保护指标无不可接受损伤。前者通过不意味着后者通过。

## 7．面向业务写作

机会发现报告按“企业有什么数据、目前怎么用 → 哪些核验事实带来新机会 → 候选想法及价值来源 → 优先方案与成本 → 最小试点、衡量与停止条件”组织。实施后的报告补上实际结果。先讲发现了什么机会、需要谁作什么决定，再给必要技术细节；附录放字段映射、计算规则和实验记录。

结果区分已核验事实、模拟/预测收益、试点观察、具有识别条件的因果增量和已兑现收益。不把预测准确率乘营业额直接写成利润，不隐去采用率或人工成本。

方案失败时报告可保留的资产：统一指标、可复查数据、排除无效动作的证据及节约的后续试错成本。未测量的节约不填具体金额。机会发现授权内可继续寻找其他候选；若替换已选主线或改变已确认目标，则先讨论再推进。

## 企业交付验收

按本轮交付核验：输入、已有用途及未知范围可核验；候选由具体数据引出，说明比现有用途可能多产生什么价值；成熟度、关键未知及补证据路径清楚。进入验证或实施时，再检查动作与结果、现状基线、成本与容量、验收与责任；收益假设和已测结果、试点和上线阶段始终区分。检查状态区分已完成、影响本轮结论但尚未完成、不适用；仅做机会发现时交付有依据的候选及验证建议，不要求已有试点或收益证明。
