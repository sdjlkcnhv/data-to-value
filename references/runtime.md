# 安装与运行环境

用于安装、发布验收或环境变更后的恢复；正常项目复用已有运行环境。技能包导入、依赖准备、功能验收是不同状态，不能仅凭上传ZIP成功就宣称所有能力已经可运行。导入器是否运行初始化脚本由宿主决定，本包不假定存在通用安装钩子。

## 明确依赖范围

| 能力 | 依赖与要求 |
|---|---|
| 版本选择、偏好确认、评分解释 | 模型及平台输入/展示能力，无需表格库 |
| 生成偏好页与评分页 | Python标准库；无需pandas、openpyxl、npm或单独评分软件 |
| CSV/TSV/JSON基础审核 | 可用Python标准库；不因读取普通文本表格强制安装pandas |
| 常用Excel读取与表格分析扩展 | `requirements-tabular.txt`中的pandas、openpyxl；安装后用CSV/XLSX样例实际检查 |
| 自动打开页面、确认回传 | 还需宿主预览或本地图形桌面、允许的本机回环通信；包导入与表格测试不能证明这些能力可用 |
| 让用户真正看到页面 | 页面须生成在会话工作区内，并经平台的文件交付/预览入口打开；生成到工作区外只保证文件存在，不保证用户能看到 |

本包提供Python 3.10及以上的初始化检查。常用表格扩展覆盖CSV/TSV和XLSX，不承诺已预装所有数据库驱动、旧版XLS引擎、PDF/OCR或模型训练库；新增格式/实现所需依赖按实际用途单独评估。依赖上下界是安装约束，不是所有Python、操作系统和宿主均通过测试的声明。

## 首次安装或维护时一次性准备

由宿主或负责安装的助手执行，用户不需要每次手动配环境。命令中的相对路径以技能目录为基准；工作目录不是技能目录时，改用技能目录的绝对路径（如 `<技能目录>/scripts/setup_environment.py`）。先检查宿主现成环境：

```text
python scripts/setup_environment.py --profile tabular
```

缺少常用表格扩展且安装范围已获授权时，执行一次：

```text
python scripts/setup_environment.py --profile tabular --install
```

默认复用通过检查的现成解释器；缺依赖时只向本技能专用的虚拟环境安装，不修改系统Python。初始化在前台等待pip完成，随后实际导入并完成CSV/XLSX读写检查，成功才记为就绪。失败只报告失败与可用范围，不留“已完成”的假回执，不无限重装。可用 `--state-dir <目录>` 指定环境和回执位置；默认位于用户目录 `.cache/data-to-value`。宿主受限、默认位置不可写时必须显式指定授权范围内的可写目录，否则初始化会以权限错误退出。环境不得打进发布ZIP，不能把另一台电脑的回执当作本机已验收。

初始化输出 `runtime.json`，记录 `profile`、真实解释器绝对路径、Python和库版本、检查时间、就绪状态及失败原因，并固定带 `page_display_and_callback: not_tested_by_environment_setup`，说明页面展示与回传能力不由此脚本验证。后续脚本和数据分析使用回执里的 `python`，不要安装到虚拟环境后又用另一个系统Python执行。无需shell激活虚拟环境：直接调用该解释器即可。只需核心页面能力时可用 `--profile core`，它不安装表格扩展；其通过不等于常用表格扩展就绪。

正式发布或在目标宿主部署时，另外验证一次：两版偏好页生成、展示、明确确认回传；已确认权重传入比较页；未选择模式时先询问；未确认偏好时不生成候选。记录测试的宿主和版本，未测的豆包账号/沙盒能力如实标未验证。

页面能力按宿主分别验证，不用一处成功推断另一处可用：

| 宿主类型 | 需要实测的内容 |
|---|---|
| 本地桌面 | 生成HTML后 `--open` 是否真的打开浏览器；打开失败时文件是否仍可用 |
| 网页宿主／侧边栏预览 | HTML生成在会话工作区后，交付工具是否给出可点击入口；预览面板是否渲染出页面；滑块调权是否生效 |
| 沙箱iframe预览 | 页面脚本能否运行；剪贴板是否可用、失败时只读文本兜底能否手动复制；确定偏好改走对话或原生输入 |
| 云端／远程 | 不生成回环接收器链接；用附件或平台预览交付，页面不回传选择 |

只在目标宿主实测通过后，才把该类页面的展示与回传标记为已验证；`--open` 报告“请求成功”不等于用户看到了页面。

## 日常调用

已初始化且环境身份未变时，沿用回执中的解释器和配置，不每次运行pip或后台装库。新项目先让用户选择版本，再显示偏好页，之后开展相关数据审核；基础页面不等Excel扩展安装。环境丢失、解释器改变、真实导入失败或新增格式时才检查受影响的能力。

导入ZIP的平台若不会执行初始化，需要在该平台完成一次安装验收；不能承诺“上传压缩包就预装全部依赖”。若平台每次重建沙盒且不支持持久环境，依赖是否保留须由平台提供，不能靠本地回执保证。缺少执行/预览权限时按主文件的对话/表格方式交付，不静默创建新的云服务或扩张用户授权。
